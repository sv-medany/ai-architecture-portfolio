# AI Architecture Portfolio

## Overview
This repository documents my AI architecture
learning journey, from initial system design
through to a production-ready architecture.

## Scenario
Design a scalable, secure, production-grade
AI assistant using modern AI architecture patterns.

## Assumptions
- Cloud-based infrastructure
- Multiple AI agents
- Scalable and secure deployment
- Production observability

## Repository Structure
- docs/: Session notes and architecture exercises
- diagrams/: Architecture diagrams and source files
- adr/: Architecture Decision Records
- capstone/: Final architecture and presentation
- mini-assignments/: Short design assignments
  - [01-marketing-ai-automation](mini-assignments/01-marketing-ai-automation/): Marketing automation with AI & agents
